# National Park Visitation Dashboard

An interactive Tableau dashboard exploring U.S. National Park visitation trends from 1929 to 2022.

<img width="1010" height="806" alt="image" src="https://github.com/user-attachments/assets/3b33f382-2cb5-444f-b0fd-d67c5c123860" />

## What it does

This dashboard visualizes nearly a century of U.S. National Park visitation data, letting you explore which states draw the most visitors, how visitation relates to park size, and how trends have shifted since 1929.

## Visualizations

- **Spatial map** — a diverging color palette highlights which states have the highest and lowest visitor counts, making regional patterns immediately visible
- **Scatter plot** — visitor counts plotted against park acreage, to assess whether bigger parks actually draw more visitors or whether other factors dominate
- **Line chart** — visitation trends over time from 1929 to 2022, surfacing long-term growth patterns and notable dips (e.g. surrounding major historical events)

## Tech stack

- **Visualization:** Tableau
- **Data prep:** Excel

## Why this project

Built to practice dashboard design fundamentals — choosing the right chart type for the right question, using color intentionally (a diverging palette for a comparison that has a meaningful midpoint), and laying out multiple views so they tell a coherent story rather than sitting as disconnected charts.

## How to view it

This is a Tableau workbook (`.twbx`). To view it locally:
1. Download [Tableau Public](https://public.tableau.com/en-us/s/download) (free)
2. Open the `.twbx` file in this repo
